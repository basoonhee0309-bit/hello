# 지빈의 닌자 코딩 노트

## 프로젝트 기획안

### 한 줄 소개

코딩을 좋아하고 나루토를 자주 보는 2007년생 지빈을 소개하는 개인 웹페이지.

### 목표

- 지빈의 소개와 관심사를 처음 방문한 사람에게 쉽고 재미있게 전달한다.
- 코딩에 대한 관심과 앞으로 배우고 싶은 것을 한눈에 보여준다.
- 모바일과 데스크톱에서 모두 편하게 읽을 수 있는 페이지를 만든다.

### 콘셉트

페이지 전체를 지빈의 성장 기록이자 '닌자 미션 노트'처럼 구성한다. 나루토에서 영감을 받은 활기찬 분위기를 사용하되, 공식 캐릭터 이미지나 로고 대신 오리지널 그래픽과 색상으로 표현한다.

### 주요 섹션

1. **첫 화면** — “안녕하세요, 지빈입니다!”라는 인사와 코딩·나루토를 좋아한다는 짧은 소개를 보여준다.
2. **나에 대해** — 2007년생이라는 정보와 성격, 관심사를 간단한 카드로 소개한다.
3. **코딩 수련 기록** — 배우고 있는 기술, 관심 분야, 완성한 프로젝트를 정리한다. 프로젝트가 아직 없다면 현재 배우는 내용부터 기록한다.
4. **좋아하는 것** — 나루토를 즐겨 보는 이유와 취미를 소개한다. 작품의 장면이나 대사를 길게 옮기지 않고 지빈 자신의 감상 위주로 쓴다.
5. **다음 미션** — 배우고 싶은 기술이나 만들어 보고 싶은 것을 체크리스트 형태로 보여준다.
6. **연락하기** — 공개해도 괜찮은 소셜 계정이나 연락 링크를 둔다.

### 디자인 방향

- 어두운 남색을 기본으로 하고 오렌지색을 포인트로 사용해 에너지 있는 분위기를 만든다.
- 미션 카드, 진행 표시, 노트 질감 같은 요소로 콘셉트를 살린다.
- 읽기 쉬운 글자 크기와 충분한 대비를 우선하고, 장식과 애니메이션은 과하지 않게 한다.
- 작은 화면에서는 섹션과 카드가 세로로 자연스럽게 이어지도록 반응형으로 구성한다.

### 첫 화면 문구 초안

> 코드를 한 줄씩 익히며 나만의 길을 찾는 중입니다.
>
> 코딩을 좋아하고 나루토를 자주 보는 지빈이에요.

### 첫 버전 범위

- 한 페이지 안에 소개, 관심사, 코딩 기록, 다음 목표를 담는다.
- 실제 프로젝트와 연락처는 지빈이 공개하고 싶은 내용을 확인한 뒤 추가한다.
- 방문자에게 보여줄 개인 정보는 필요한 범위로 제한한다.
